PromptBox Profile-Guided Onboarding Test

This page tests the new profile-guided onboarding features.

Test Scenarios

PromptBox

Expected Behavior

  • New User: Shows welcome message with "Import from URL" and "Describe my business" buttons
  • Incomplete Profile: Shows completion percentage and suggests missing fields with action buttons
  • Complete Profile: Shows ready state with example prompts and business name

Button Interactions

  • Clicking "Import from URL" should pre-fill input with "/import "
  • Clicking "Describe my business" should focus the input
  • Clicking "Add [Field]" should pre-fill input with the appropriate command
  • Clicking "Start creating →" should focus the input
